🎬 Наценка и расчет стоимости видео (PixVerse V6)

Управление торговой наценкой на видеоролики над себестоимостью API Kie.ai

СОМ
📊 Формула гибридного ценообразования:
• Себестоимость API PixVerse V6 (720p): 7.2 кредита/сек (~3.17 сом/сек).
• Для видео 5 сек: себестоимость ≈ 16 сом (36 кр). С наценкой +250 сом = 270 сом.
• Для видео 8 сек: себестоимость ≈ 25 сом (58 кр). С наценкой +250 сом = 280 сом.
• Для видео 10 сек: себестоимость ≈ 32 сома (72 кр). С наценкой +250 сом = 290 сом.

Кнопка мгновенно пересчитает цену каждого видео-шаблона по его длительности (Себестоимость + Наценка) и сохранит в облако. При этом в редакторе любого шаблона вы по-прежнему можете задать любую фиксированную цену вручную (например, 350 сом).
